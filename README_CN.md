# PEP-Web 阅读模式 —— Chrome 插件

[English](README.md) | **中文**

让 PEP-Web 上的精神分析文献，变得更安静、更舒适、更适合真正的阅读。PEP-Web 是一个极其宝贵的文献库，但阅读体验常常令人疲惫。这个插件希望把 PEP-Web 的文章，变成更接近书籍或学术期刊的阅读体验，而不是普通网页。

## ✨ 新版本亮点

### 🔄 全新阅读结构
插件不再直接修改原始网页结构，而是创建一个 **独立的阅读 overlay**。
- 可随时开关阅读模式
- 无需刷新页面
- 通过工具栏图标或快捷键即可顺滑切换

### 🌍 与沉浸式翻译良好协作
本插件与 **Immersive Translation（沉浸式翻译）** 兼容效果很好，
既能保持安静、舒适的阅读排版，又适合双语阅读或辅助理解的场景。

### 🎨 优雅的阅读主题
精心设计的三个主题：

**Classic**  
清爽、平衡、适合日常阅读。

**Paper**  
温暖纸张底色 + 更具书籍感的衬线字体，更接近纸质书 / 学术期刊的阅读体验，适合长时间沉浸式阅读。

**Night Mode**  
柔和的深色主题，适合夜间阅读。

### 📚 References 与 Footnotes —— 更可控

现在你可以：
- 随时隐藏或显示 References 和 Footnotes

既提升可读性，又不牺牲学术严谨。

### 🔍 快速搜索 —— 快速定位文献
提供一个简洁的作者 / 年份快速搜索弹窗：
- 可通过快捷键打开（默认 Command+Shift+P）
- 自动聚焦输入框
- 手不离键盘即可操作

### 📝 导出为 Markdown
可将文章导出为结构清晰的 Markdown 文档：
- 保留标题层级
- 支持粗体 / 斜体
- quotation / dream / poem 段落会自动转为 Markdown 引用形式
- 更适合知识库与长期整理

### 🧠 智能文件名生成
导出 Markdown 时，将自动根据文献信息生成文件名，例如：

`Ogden, T. H. (2004) The Analytic Third - Implications for Psychoanalytic Theory and Technique.md`

- 更贴近学术习惯  
- 自动去除期刊尾部信息  
- 兼容 Windows 与 macOS 文件系统规则

### ⌨️ 快捷键
可在 `chrome://extensions/shortcuts` 自定义。

**切换阅读模式**
- macOS：`Command + Shift + L`
- Windows：`Ctrl + Shift + L`

**打开搜索弹窗**
- macOS：`Command + Shift + P`
- Windows：`Ctrl + Shift + P`

## 🧩 安装方法

1️⃣ 打开： `chrome://extensions`
2️⃣ 启用 **开发者模式**
3️⃣ 点击「加载已解压的扩展程序」
4️⃣ 选择本项目文件夹

完成 🎉
