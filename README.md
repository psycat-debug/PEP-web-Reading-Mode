# PEP-Web Reading Mode – Chrome Extension

English | [中文说明](README_CN.md)

A cleaner, calmer and more readable way to experience psychoanalytic literature on PEP-Web. PEP-Web is an extraordinary archive — but its reading experience is often tiring. This extension turns PEP-Web articles into something that feels closer to a book or academic journal rather than a web page.

## ✨ Highlights of the Latest Version

### 🔄 Rebuilt Reading Experience
Instead of modifying the original webpage structure, the extension now creates a **dedicated reading overlay**.
- instantly toggle reading mode on/off
- no page refresh required
- enter and exit smoothly via toolbar icon or shortcut (default Command+Shift+L)

### 🌍 Works Great with Immersive Translation
This extension works smoothly alongside **Immersive Translation**, making it easier to read bilingually or to use translated support while staying in a calm, book-like reading layout.

### 🎨 Beautiful Reading Themes
Three thoughtfully designed themes:

**Classic**  
Clean, balanced, and comfortable for everyday reading.

**Paper**  
Warm paper tone + elegant serif typography, closer to book / journal reading, ideal for immersive long-form reading.

**Night Mode**  
Soft dark theme for evening reading comfort.

### 📚 References and Footnotes — Under Your Control
Depending on what you’re doing, sometimes you want them visible, sometimes you don’t.

Now you can:
- toggle References and Footnotes on/off anytime

Academic rigor + good readability.

### 🔍 Keyboard-Driven Quick Search
A compact Author / Year search popup:
- opened via keyboard shortcut (default Command+Shift+P)
- automatically focuses input
- fast interaction without leaving the keyboard

Perfect for:
- cross-checking citations
- running parallel reading
- jumping between related works

### 📝 Export to Markdown
Export the article to a clean Markdown document:
- preserves important markdown syntax for headings / bold / italics
- quotation / dream / poem style text is automatically formatted as Markdown blockquote content
- cleanly structured for note systems and knowledge bases

### 🧠 Smart Filename Generation
When exporting Markdown, filenames are automatically generated from article metadata:

Example:

`Ogden, T. H. (2004) The Analytic Third - Implications for Psychoanalytic Theory and Technique.md`

- follows academic naming habits  
- removes trailing journal details  
- compatible with both Windows & macOS filename rules

### ⌨️ Keyboard Shortcuts
Default suggestions (can be customized in `chrome://extensions/shortcuts`):

**Toggle Reading Mode**
- macOS: `Command + Shift + L`
- Windows: `Ctrl + Shift + L`

**Open Search Popup**
- macOS: `Command + Shift + P`
- Windows: `Ctrl + Shift + P`

## 🧩 Installation

1️⃣ Open: `chrome://extensions`
2️⃣ Enable **Developer Mode**
3️⃣ Click **Load Unpacked**
4️⃣ Select this project folder

Done 🎉

This extension is built to:
- reduce friction,
- support deep engagement,
- respect how people really read.

So that the focus can return to thinking and reflecting.
